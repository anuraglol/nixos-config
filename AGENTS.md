# NixOS Configuration — Agent Notes

## What this repo is

This is a **NixOS flake** (system configuration), not a software project. There are no tests, build scripts, or package managers in the traditional sense. The entire system is built from a single `flake.nix` that assembles the NixOS configuration and Home Manager setup.

## Architecture

| Entrypoint                   | Role                                                                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `flake.nix`                  | Defines the system `neko` (hostname), wires `nixpkgs`, `nixpkgs-unstable`, and `home-manager` inputs.                                             |
| `configuration.nix`          | System-level configuration (boot, networking, services, filesystem mounts, users, packages).                                                      |
| `home.nix`                   | Home Manager entrypoint. Imports modules from `modules/`.                                                                                         |
| `modules/`                   | Feature modules: `hardware.nix`, `gnome.nix`, `packages.nix`, `dconf.nix`, `fish.nix`, `fastfetch.nix`, `zed-editor.nix`, `kitty.nix`, `git.nix`. |
| `hardware-configuration.nix` | **Auto-generated** by `nixos-generate-config`. Do not edit. Modify `configuration.nix` or `modules/hardware.nix` instead.                         |

## Channels

- **Stable**: `nixos-26.05` (primary, used for everything).
- **Unstable**: `nixos-unstable` (used for exactly 2 packages: `zed-editor` and `claude-code`).

The unstable set is passed into modules as `unstable-pkgs` via `_module.args` and `home-manager.extraSpecialArgs`.

## Developer commands

- **Validate the flake** (fast, no side effects):
  ```bash
  nix flake check
  ```
- **Build and activate the system** (requires sudo, applies changes immediately):
  ```bash
  sudo nixos-rebuild switch --flake .#neko
  ```
- **Dry-run build** (shows what would change without activating):
  ```bash
  sudo nixos-rebuild dry-activate --flake .#neko
  ```
- **Update flake inputs** (pins new revisions for all channels):
  ```bash
  nix flake update
  ```

## Workflow notes

- **Edit → validate → rebuild** is the standard cycle. There is no separate lint or test step.
- `nixpkgs.config.allowUnfree = true` is set globally, so unfree packages are allowed.
- The system is pinned to `stateVersion = "26.05"`. Do not change this unless migrating to a new NixOS release.
- Home Manager is integrated as a **NixOS module** (`home-manager.nixosModules.home-manager`), not a standalone `home-manager` CLI tool.
- `nix` reads a GitHub token from `/etc/nix/github-token.conf` (included via `nix.extraOptions`). If building from a fresh environment, this file must exist.

## Storage layout (non-obvious)

- `/data` is a separate partition mounted at boot.
- `/home/anurag/Documents`, `Downloads`, and `Videos` are **bind mounts** from `/data`.
- `/etc/nixos` is a symlink to this repo on disk.
- The real path is `/data/Documents/nixos-config`. The bind mounts happen before symlink resolution, so there is no circular dependency.

## Editing constraints

- **Never edit `hardware-configuration.nix`**. It is generated by `nixos-generate-config` and will be overwritten on future runs.
- Adding new packages usually belongs in `modules/packages.nix` (home packages) or `environment.systemPackages` in `configuration.nix` (system packages).
- Only use `unstable-pkgs.<name>` if the package is known to be missing or too old in the stable `26.05` channel.
- GNOME settings and dconf overrides live in `modules/dconf.nix` and `modules/gnome.nix`. These files are heavily GNOME-specific.
- Fish shell configuration is in `modules/fish.nix`.
- `modules/zed-editor.nix` is large because it contains the full Zed settings JSON as Nix attribute sets. Keep edits to that file scoped to Zed settings only.
